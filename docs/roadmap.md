# Roadmap

What gets built next, in order. Each phase is its own branch; the full working plan (with status) is kept in the
Home Lab project as `argus-roadmap.md`.

1. **Helios usability**: Plugins page with per-plugin controls (done); modern terminal look with a full-width map,
   inspector drawer, events dock and smooth motion (done); a home page that answers "is everything
   fine?", an Approvals inbox, Settings and Models pages, a cleaner phone view.
2. **Guidance loop**: samples, verdicts, nightly lessons with test scores (done); replay with another model, a tests
   page per playbook, lessons that don't help are not offered.
3. **Tracker / Life Hub connector**: Ari lists, creates and moves issues (needs the tracker's location).
4. **Research ports**: the daily digest and the structural-break research agent as plugins.
5. **Money**: Cashly connector, bill filer, bank SMS, a Cashly panel (always approved; totals in code).
6. **Laptop move**: deploy/README.md, when the NVMe arrives.
